# Pong-Variations

Music note asset from: https://opengameart.org/
Piano and number assets made from Canva
Ending Screen made from Canava


Game includes:
- Single-Player Switch: can switch from double player mode (deafult) to single player mode by pressing 't'
- Custom ball / music note generation: by pressing a number from 1 to 5 - that amount of balls will appear!

The player that reaches 8 points first wins!
